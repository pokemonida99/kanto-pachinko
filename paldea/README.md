# 帕底亞刮刮樂（paldea/）

第九世代・帕底亞台。帕底亞圖鑑 400 隻，玩法是**刮刮樂**：打開就能刮，不用動腦。

## 怎麼玩
- 畫面中央一張 3×3 刮刮卡。用手指或滑鼠在銀色塗層上刮；一格刮開超過 60% 就自動整格掀開。
- 每張卡**保證至少一組「三個相同」**（約 18% 會有兩組）。三個都刮出來 → 金邊亮起、揭曉卡片，那隻寶可夢就收進圖鑑（閃光 1/100）。
- 卡片顏色＝這張卡的屬性（18 種屬性各有配色與圖示），九格都只會出這個屬性的寶可夢；每張卡屬性都不一樣。
- 三連都刮出來後，剩下的格子自動掀開，卡片飛走、下一張滑進來，無限張。
- 「✨ 全部刮開」給懶人；「自動刮」開關（預設關）會有一枚金幣自己慢慢刮。
- 同一隻收集 3 隻會自動進化（共用 `C.evolve()`）。

## 特別的卡
- **太晶卡**：每 7 張一張。整張彩虹全息、寶石切面動畫、音樂變亮；三連得到的那隻**必定閃光**。
- **傳說卡**：每 25 張一張。故勒頓 → 密勒頓 → 第三格（太樂巴戈斯不在帕底亞圖鑑，改從名單裡的傳說 古簡蝸／古劍豹／古鼎鹿／古玉魚 隨機）輪流；三連必得傳說，金色專屬演出。

## 介面
- 圖鑑（依帕底亞編號、每頁 40 隻、可依屬性篩選、點有閃光的切換閃光圖）、最近抓到、🏠 回大廳、🎵 音樂／🔊 音效開關（WebAudio 即時合成）。
- 桌機（≥1000px）：卡片大，左邊「這張卡＋屬性收集」，右邊「最近抓到＋圖鑑」。手機直向：卡片填滿寬度，下方按鈕與最近抓到。

## 存檔
- 圖鑑：`paldeaPachinko.dex`（共用格式，大廳會合併）。
- 第幾張／傳說輪替／聲音開關：`paldeaPachinko.state`。網址加 `?reset` 會清掉兩者。

## 測試用（瀏覽器 console）
`PD.tera()` 下一張變太晶卡、`PD.legend()` 下一張變傳說卡、`PD.skip()` 直接換下一張、`PD.revealAll()`、`PD.auto(true)`、`PD.check()` 檢查目前這張的三連。

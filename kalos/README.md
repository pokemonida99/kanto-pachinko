# 卡洛斯卡包研究所（kalos/）

第六世代・卡洛斯台：**開寶可夢卡包**。不用動腦，挑一包、撕開、翻牌、收進卡冊。

## 玩法
- 桌上有三種卡包：**中央（粉）／海岸（藍）／山岳（紫）**，對應卡洛斯三本地區圖鑑（`sub` 0/1/2）。
- 點一包拿起來 → **往上拖封口撕開**（或點一下）→ 5 張卡攤開（桌機一排扇形、手機 3＋2 兩排）。
- 點卡片翻面；翻完 4 張後，**第 5 張自動慢翻**（這包最稀有的那張放最後，稀有以上會先閃邊光）。
- 卡框：普通白框／稀有銀框／超稀有金框／傳說彩虹框；**閃卡 1/60**（全息滿版＋亮片）。超稀有、傳說、閃卡會有特寫揭曉。
- 翻完 5 張一起收進圖鑑，新的會蓋「新登錄」章；同一隻 3 張自動進化。點一下收進卡冊，桌上自動補新包。
- **⚡ 一鍵開包**：自動撕、自動翻；打開「連開」就一直開，再按一次停止。
- 每開 10 包是**特別包**（金色，保證超稀有以上，偶爾是該套傳說）；每開 30 包是**傳說包**（彩虹，保證 哲爾尼亞斯 → 伊裴爾塔爾 → 基格爾德 輪流）。
- **卡冊**：三個頁籤（中央／海岸／山岳），每頁 9 格、翻頁動畫（桌機雙頁攤開），格子顯示該本編號 #subNo 與名字；點卡片看大圖，有閃光的點大圖切換閃光。
- 卡片會跟著滑鼠位置或手機陀螺儀傾斜，全息反光跟著移動（iPhone 第一次點會問動作權限）。

## 技術
- 載入順序：`data.js` → `../shared/collect.js` → `game.js`；圖片 `../all/assets/`。
- 圖鑑存檔 `kalosPachinko.dex`（共用格式）；開包計數與音樂設定存在 `kalosPachinko.state`。
- DOM＋CSS 3D 翻牌、Canvas 只畫粒子；WebAudio 即時合成手風琴圓舞曲與音效（♪／🔊 開關）。
- 測試：主控台 `__kalos.setOpened(29)`（下一包傳說包）、`__kalos.openN(10)`；網址加 `?reset` 清空。

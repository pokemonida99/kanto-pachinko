# 寶可夢彈珠研究所

寶可夢主題的收集小遊戲合集：一個入口大廳，十一台玩法與介面都不同的機台，任何一台抓到的都會進大廳的全國圖鑑。打開就能玩，沒有任務、沒有結算、沒有失敗。

**線上玩：** https://pokemonida99.github.io/kanto-pachinko/

每台的玩法細節看各資料夾裡的 README。各世代用該世代的地區圖鑑編號（含舊角）；跨世代台與大廳的全國圖鑑用全國編號。

## 共同規則
- 每台都是「抓到就進圖鑑」，同種集滿 3 隻自動進化，閃光約 1/100
- 各台圖鑑各自獨立，大廳把所有台抓到的合併成全國圖鑑（1025 隻）
- 前三台是柏青哥（一局 100 顆、每 30 秒開箱、兩側落空幫傳說充能、搖台搖太兇會 TILT）；其餘八台沒有彈珠數也沒有結算，想玩多久就玩多久
- 大廳的「隨便玩一台」會隨機跳到一台

## 結構
```
index.html      入口大廳（皮卡丘打招呼、選機台、全國圖鑑牆）
all/            全國 1–1025 的 data.js 與圖片（第四代以後的機台共用）
shared/         collect.js 共用圖鑑存檔工具、大廳用的皮卡丘圖
kanto/ johto/ hoenn/           前三台各自有 index.html、game.js、data.js、assets/
sinnoh/ … paldea/ fishing/ claw/   其餘各台：index.html、game.js、data.js（跨世代台用 all/data.js）
tools/fetch_gen.py     從 PokeAPI 抓資料與圖：python3 tools/fetch_gen.py galar dex galar --no-images
計畫.md         製作計畫與各台規格
```
圖鑑存在瀏覽器 localStorage（每台 `<資料夾>Pachinko.dex`），大廳合併顯示。

## 技術
純 HTML／Canvas／WebAudio，無需建置。本機測試請用任一靜態伺服器（例如 `python3 -m http.server 8780`）開根目錄。背景音樂與音效為程式即時合成的原創曲。各台網址加 `?reset` 可清除該台存檔。

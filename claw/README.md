# 寶可夢夾娃娃機（claw/）

跨世代機台：玩偶池是全國 1–1025 隻。每次都免費，沒有代幣、沒有失敗。

## 怎麼玩
- 按住 ◀ ▶（或鍵盤方向鍵、在機台裡拖曳）移動爪子，按「下爪」（空白鍵）。
- 直接點玩偶，爪子會自己移過去；爪子已經在它上面時再點一次就下爪。
- 滑鼠停在玩偶上（手機長按）會顯示 #全國編號、名字、稀有度。
- 「🤖 自動夾」預設開：放著它會自己挑一隻夾；你一操作就讓你來，停手 3.5 秒後再接手。

## 機率與規則
- 夾到機率：普通 70%、稀有 45%、超稀有 25%、傳說 10%。沒夾到＝玩偶在半路滑落（「啊～」＋晃動），免費再來。
- 保底：連續 5 次沒夾到，第 6 次必定夾到（機台上 5 顆保底燈）。
- 機台裡固定 16 隻玩偶；抓走一隻就從上面掉一隻補（`C.pick()`，boost 0）。每補 8 隻出一隻金光玩偶（boost 2），每補 40 隻出一隻傳說玩偶（大一號、發光）。
- 閃光 1/100，閃光玩偶會一閃一閃。每 60 秒店員整理一次（玩偶跳起來重排）。
- 掉進出貨口有「咚」聲和揭曉卡片；超稀有／閃光／傳說有聚光燈演出，傳說另有跑馬燈全亮＋紙花。
- 同種集滿 3 隻自動進化（`C.evolve()`）。

## 技術
- 載入 `../all/data.js` → `../shared/collect.js` → `game.js`；存檔 `clawPachinko.dex`（大廳合併用），開關設定另存 `clawPachinko.cfg`。
- 純 Canvas＋WebAudio（原創 F 大調街機曲、爪子馬達、啊～、咚），音樂音效可分開關。
- 測試：主控台 `__claw.legend(true)` 立刻補一隻傳說玩偶並讓下一次自動夾必中；`__claw.speed(4)` 加速；`__claw.state()` 看狀態。網址加 `?reset` 清空圖鑑。

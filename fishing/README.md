# 🎣 寶可夢釣魚台（跨世代．全國水系）

黃昏的海邊碼頭，甩竿、等浮標沉下去、收線，把全國 **154 隻水系寶可夢**（`POKEDEX.filter(p => p.types.includes('water'))`，一到九代）釣進圖鑑。
沒有任務、沒有失敗，打開就能釣，放著自動釣也可以。

## 怎麼玩
| 動作 | 說明 |
|---|---|
| **點一下**畫面（或下方大鈕、空白鍵） | 隨便甩一竿 |
| **按住**再放開 | 按越久甩越遠（力道條）：近的**淺灘**普通寶可夢多，中間**近海**，遠的**深海**稀有多 |
| 浮標猛沉＋「！」 | **1.2 秒內點一下**就上鉤；錯過只會「魚跑了～」，再甩就好 |
| 上鉤後**按住** | 收線 1.5 秒（進度條，不用對時機，放開只是暫停） |
| 魚跳出水面 | 剪影 → 最高點慢動作閃光變彩色 → 揭曉卡片 |
| **自動**開關（預設開） | 自己甩、自己點、自己收；你隨時也能自己按 |

- 第一次釣到、稀有以上、閃光會出大卡片（點一下關閉，自動模式會自己關）；重複的普通寶可夢只在右上角跳小卡，不打斷節奏。
- **閃光** 1/100，卡片有彩虹框。
- **傳說**（水君、蓋歐卡、帕路奇亞、霏歐納、瑪納霏、凱路迪歐、波爾凱尼恩、卡璞・鰭鰭，共 8 隻）只在**深海**出現，約 1/60；上鉤時浮標瘋狂抖動、海面發光出現光柱。
- 同種 3 隻自動進化（例如鯉魚王 ×3 → 暴鯉龍），進化演出後登錄。
- 偶爾釣到雜物：
  - 🥾 **舊鞋子**：搞笑一下。
  - 🎁 **寶箱**：得到「大師餌」，下一竿保證稀有以上（畫面上會掛著紫色的餌、浮標變紫）。
  - 🍾 **瓶中信**：皮卡丘寫給你的一句話。
- 海面上偶爾有魚影游過、海鷗飛過（純氛圍）。

## 日夜
依真實時間：06:00–18:00 是黃昏夕陽，18:00–06:00 是月光海面、星星與碼頭燈籠。網址加 `?night` / `?day` 可以強制切換。

## 介面
- 桌機（≥1000px 或橫向）：左邊寬海面，右邊木框側面板（圖鑑進度、甩竿鈕、自動、最近釣到、音樂／音效、回大廳、玩法）。
- 手機直向：海面填滿上方，下方是最近釣到＋甩竿大鈕＋自動／圖鑑；頂端有回大廳、圖鑑數、音樂、音效。
- 圖鑑：分頁（左右鍵、滑動）、全國 #編號、篩選（全部／已釣到／還沒釣到／閃光／傳說），釣過閃光的格子點一下切換顏色。
- 音樂（慢板撥弦＋口哨旋律）與音效（海浪、海鷗、甩竿、水花、揭曉）全部 WebAudio 合成，各有開關。

## 存檔
- 圖鑑：`fishingPachinko.dex`（`shared/collect.js` 格式，大廳 `Collect.union()` 會合併）。
- 設定（自動、音樂、音效、大師餌數）：`fishingPachinko.cfg`。
- 網址加 `?reset` 清空圖鑑。

## 測試用
瀏覽器 console：
```js
__fish.force('legend', 'chest', 129, 129, 129, 'bottle', 'shoe', 'shiny') // 指定接下來幾次上鉤的結果（數字＝全國編號）
__fish.speed(4)    // 時間倍速
__fish.state()     // 目前狀態、圖鑑數、最近釣到
__fish.night(true) // 切夜景
```

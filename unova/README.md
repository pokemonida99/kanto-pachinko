# 合眾彈珠打磚（unova/）

第五世代・合眾地區的機台：**Peggle 型彈珠打磚**。黑白雙色台面，配色和音樂跟著四季變。
沒有分數、沒有關卡、沒有失敗，珠子無限，打開就能看它自己打。

## 怎麼玩
- **瞄準射擊**：在台面上按住拖曳瞄準（會畫出虛線預測軌跡的前段），放開射出；不想瞄就點一下，直接朝那個方向射。鍵盤：← → 轉砲口、空白鍵射。
- **一次一顆**：珠子落底後才能射下一顆。
- **自動連發**（預設開）：砲台會自己挑一個方向射，放著看就好。
- **藍釘**：普通釘子，碰到會亮，珠子落底後依序消失。
- **橘色寶可夢釘**（每台 15 顆）：釘上畫著一隻合眾寶可夢，打到就抓到。先亮起來，落底後一次揭曉這顆珠抓到的全部寶可夢。
- **底部桶子**：左右來回，接到珠子＝「FREE BALL!」小演出。
- **清台**：打完全部橘釘。最後一顆會進慢動作、鏡頭拉近、音樂拔高；清台後送一隻該季節的稀有寶可夢，然後換下一季、釘子重新排列。
- **四季**：春（櫻粉、櫻花）→ 夏（翠綠、螢火蟲）→ 秋（楓橘、楓葉）→ 冬（冰藍、下雪）。冬天釘子結冰，珠子碰到會滑一下（反彈 ×1.2、方向亂偏 ±15°）。
- **龍釘**：每清 3 台出現一顆大的龍釘，捷克羅姆 → 雷希拉姆 → 酋雷姆輪流。打到就抓到傳說的龍；沒打到會留到下一台。
- 閃光 1/100；同一種抓到 3 隻會自動進化。

## 介面
- 桌機（≥1000px）：左邊白色面板放季節、圖鑑進度、剩下的寶可夢釘、龍釘；右邊黑色面板放最近抓到、開關、暫停。
- 手機直向：台面佔滿，底部一排小鈕（大廳、圖鑑、最近、自動、暫停、音樂、音效）。
- 圖鑑：合眾圖鑑 301 隻，顯示地區編號 #no，可分頁、左右滑，有 ✨ 的格子點一下切換閃光。

## 檔案
- `data.js`：合眾圖鑑（B2W2，301 隻）
- `index.html`：版面與樣式
- `game.js`：物理、釘板樣板、演出、音樂音效、圖鑑
- 圖片共用 `../all/assets/`；存檔用 `../shared/collect.js`，key 是 `unovaPachinko.dex`（大廳合併成全國圖鑑）。機台狀態（季節、清台數、龍釘、開關）另存在 `unovaPachinko.state`。

## 開發用
- 網址加 `?reset` 清掉這台的存檔。
- Console：`__sim(300)` 不畫面、不存檔，用自動連發跑 300 秒物理，回報射幾顆、清幾台、卡珠保險觸發幾次、有沒有 NaN、最長一顆飛幾秒。
- Console：`__dev.clear()` 直接清台、`__dev.dragon()` 這台放龍釘、`__dev.season(3)` 切到冬天。

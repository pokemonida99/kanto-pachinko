# 阿羅拉・草叢散步（alola/）

第七世代・阿羅拉地方（究極之日／究極之月的阿羅拉圖鑑 403 隻）。
一顆長了兩隻小腳的精靈球自己在熱帶島嶼上往右走，草叢裡跳出寶可夢，丟球收集。
**完全不操作也能玩**：預設自動丟球，放著就會一直走、一直抓、一直換島。

## 怎麼玩

| 動作 | 效果 |
| --- | --- |
| 什麼都不做 | 自動模式（預設開）：主角自己走、自己丟球 |
| 點畫面任何地方 | 寶可夢剪影出現時＝丟球 |
| 按住畫面 | 走路時加速跑 |
| 空白鍵 | 同點畫面／按住 |
| P／D | 暫停／打開圖鑑 |

- 走近草叢 → 草叢搖晃、冒出「！」→ 跳出一隻**剪影**（稀有以上會有藍／金／紫色光暈，閃光會冒星星）。
- 丟球 → 球打開把寶可夢吸進去 → 落地搖三下（每下都有音效）→「喀」抓到 → 剪影從球裡跳出來變成彩色 → 揭曉卡片（#地區編號、名字、稀有度、NEW、閃光）。
- 超稀有、傳說、究極異獸、閃光改用全畫面聚光燈演出（點一下或 3 秒後自動繼續）。
- 依球種顯示：普通＝精靈球、稀有＝超級球、超稀有／傳說＝高級球、究極異獸＝究極球。
- 同一種抓到 3 隻會自動進化（共用 `Collect.evolve()`），有進化演出。

### 沒有失敗

逃走機率依捕獲率：`0.5 × (1 − ln(capture/3) / ln(85))`
→ capture 255 約 0%、190 約 3%、45 約 20%、3 約 50%。
**逃走的那隻會在下一個草叢再出現一次，而且第二次必中**（究極之洞逃走的會在下一叢再開一次洞）。

### 閃光

每隻 1/100。

## 四座島與名單

每 42 秒（遊戲時間）換一座島，中間有船或大鳥載著飛過去的轉場，島名大字出現。順序循環：

| 島 | 地區編號 | 配色 | 遠景 |
| --- | --- | --- | --- |
| 美樂美樂島 | #001–#100 | 黃綠 | 圓丘 |
| 阿卡拉島 | #101–#200 | 粉紅 | 會冒煙的火山 |
| 烏拉烏拉島 | #201–#300 | 紫夜 | 雪峰 |
| 波尼島 | #301–#403 | 藍 | 峽谷台地（有層紋） |

草叢名單＝該島地區編號範圍內、**排除傳說／幻之與究極異獸**，用 `C.pick()` 依捕獲率加權（越好抓越常出）。
夜晚有 30% 機率優先出幽靈／惡／超能力／妖精／蟲屬性。

## 特別事件

- **究極之洞**：每到一座島擲一次 1/3，中了就在這座島的 8–32 秒之間觸發。畫面變暗、天空裂開、打雷，從裂縫降下一隻：
  - 45% 究極異獸（793–799、803–806，名單裡有的都算）
  - 35% 該島守護神（美樂美樂＝卡璞・鳴鳴、阿卡拉＝卡璞・蝶蝶、烏拉烏拉＝卡璞・哞哞、波尼＝卡璞・鰭鰭）
  - 20% 其他傳說／幻之（屬性：空、銀伴戰獸、基格爾德、科斯莫古一族、奈克洛茲瑪、瑪機雅娜、瑪夏多、捷拉奧拉）
- **寶箱**：路邊偶爾出現（手上沒有超級餌時，約每 6 叢以上有 13% 機率）。撿到送「超級餌 ×3」，接下來 3 隻保證稀有以上。

## 畫面

- 全部 Canvas 幾何＋漸層：天空、太陽／月亮、雲、遠山（四島不同造型）、近丘、海（波紋、反光）、浪花沙灘、椰子樹（會搖）、小路、花、草叢、前景草；偶爾飛過海鷗，腳步揚塵。
- 日夜依真實時間：18:00–06:00 是夜景（星星、月亮倒影、螢火蟲、BGM 變慢變輕）。網址加 `?day` 或 `?night` 可強制。
- 數字／英文用 Google Fonts「Fredoka」，中文 Noto Sans TC。
- 桌機（≥1000px）：左側島嶼進度與開關、中間寬場景、右側最近抓到；手機直向：場景填滿上方，下面一條最近抓到、一排小按鈕。

## 音樂音效

WebAudio 即時合成。BGM 是烏克麗麗刷弦（鋸齒＋三角波過快速關閉的低通當撥弦），夏威夷轉圈和弦 C–C–A7–A7–D7–G7–C–G7，每座島移調；夜晚改慢版。
音樂、音效各自有開關（記在 `alolaPachinko.cfg`）。瀏覽器要求先點一下畫面才會出聲（畫面左下有提示）。

## 存檔

- 圖鑑：`alolaPachinko.dex`（`shared/collect.js` 格式，大廳 `Collect.union()` 會合併）。
- 設定：`alolaPachinko.cfg`（自動、音樂、音效）。
- 網址加 `?reset` 清空本台圖鑑。

## 測試用

瀏覽器 console：

```js
__alola.worm()     // 立刻觸發究極之洞
__alola.island()   // 立刻換島
__alola.chest()    // 前面放一個寶箱
__alola.shiny()    // 下一叢必定閃光
__alola.speed(4)   // 遊戲時間 4 倍速
__alola.state()    // 目前狀態、島、抓到幾隻
```

# 神奧推幣機（sinnoh/）

第四世代・神奧地區的機台：一台夜市那種**推幣機**（coin pusher）。打開就會自己投珠、自己推，看著寶可夢玩偶一隻隻被推下去就好。

## 怎麼玩

- **點畫面**：從玻璃頂投一顆珠，落點就是你點的左右位置；**按住**每 0.25 秒投一顆，可以拖著瞄。
- **自動投珠**（上方「自動」，預設開）：機台自己左右掃著投，完全不用動手。
- 珠無限、不計數；台面上最多 60 顆。
- 推板每 3 秒前後推一次，把平台上的珠和玩偶往前擠。
- **珠掉下前緣**：回收，出口槽閃一下、數字 +1。
- **玩偶掉下前緣**：抓到那隻寶可夢，馬上跳出揭曉卡（名字、神奧編號 #no、稀有度、NEW、閃光彩光）。抓很多隻會排隊一張一張出，點一下或 2 秒自動換下一張，遊戲不會停。
- 玩偶的底座顏色就是稀有度：珍珠白＝普通、鑽石藍＝稀有、金色＝超稀有。閃光玩偶（1/100）會帶彩虹框和亮粉。
- 平台上隨時保持 6～10 個玩偶，每 4 秒從後方降下一個（依捕獲率抽）。
- 同一種抓滿 3 隻會自動進化（揭曉卡會接著跳「EVOLUTION」）。

## 特別事件

- **側溝與時空能量**：平台前半段兩側是側溝，珠被擠進去不會回收，但會累積上方時空之門的「時空能量」。滿 100% 時畫面時空扭曲，平台中央降下一個**超大傳說玩偶**，推下去就抓到（慢動作＋專屬揭曉卡）。
  - 順序：帝牙盧卡 → 帕路奇亞 → 騎拉帝納 輪流；第 4、8、12…次換成由克希／艾姆利多／亞克諾姆／瑪納霏（讓 7 隻傳說都收得到）。
  - 玩偶比側溝大，不會掉進去，只有珠會。
- **寶珠與寶石時間**：每投 40 顆珠，會改掉下一顆寶珠（金剛寶珠／白玉寶珠／白金寶珠輪流）。推下前緣就是 **10 秒寶石時間**：推板速度 ×2、玩偶補充 ×3，音樂也會變快。

## 介面

- 🏠 回大廳、自動、⏸ 暫停（也可按 P）、🎵 音樂、🔊 音效、📖 圖鑑。
- 圖鑑：神奧圖鑑 210 隻，每頁 30 格，顯示 #地區編號；抓過閃光的格子有 ✨，點一下切換閃光圖；可進化的種類會顯示 n/3。最上面一排是最近抓到。
- 桌機（≥1000px）左邊是收集進度與玩法說明，右邊是最近抓到與機台狀態；手機直向機台佔滿畫面。
- 音樂音效都是 WebAudio 即時合成（原創曲）。

## 技術備註

- 載入順序：`data.js` → `../shared/collect.js` → `game.js`；圖片用 `../all/assets/`。
- 圖鑑存檔：`sinnohPachinko.dex`（Collect 共用格式，大廳合併用）。設定（音樂、音效、自動、傳說輪到第幾隻）另存 `sinnohPachinko.cfg`。台面上的珠、能量不存，每次打開都是新的一台。
- 網址加 `?reset` 會清掉圖鑑存檔並把傳說順序歸零。
- 物理：平台上的東西都是 2D 圓，用「位置分離＋法向衝量」解碰撞（4 次迭代），每幀速度 ×0.9；推板是無限質量，碰到推板的物件當成釘住；中心越過前緣就進入掉落動畫。畫面用簡單的透視投影畫成 2.5D。
- 主要參數都在 `game.js` 開頭（`EN_COIN`、`GEM_EVERY`、`DOLL_EVERY`、平台大小、推板行程…）。
- 測試用：主控台 `__sp.stats` 看統計、`__sp.run(秒)` 不畫圖快轉並回報異常、`__sp.check()` 檢查卡在推板／飛出平台／NaN、`__sp.energy(100)` 直接叫出傳說。
